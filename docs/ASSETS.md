# Asset overview

Impact frames and scene textures are rendered by `tools/generate_art.py`, icons by `tools/generate_placeholders.py`. Replace a file with your
own PNG of the same name; keep the aspect ratio. Paths are relative to `src/main/resources/assets/skysdomains/`.

### Scene texture roles

| Texture | Used by |
|---|---|
| `scene/sphere_<domain>.png`, `scene/sphere_default.png` | domain sphere wall (`sphere.texture` in the sequence file); scrolls horizontally |
| `scene/sky_space.png`, `scene/sky_none.png` | reserved for custom sky boxes (`sky` action) – currently the sphere wall itself shows the stars (`inside_opaque`) |
| `scene/planet_<name>.png` (mercury … neptune), `scene/planet_generic.png` | Structural Collapse planets (UV spheres) |
| `scene/sun.png`, `scene/white_hole.png`, `scene/ring_saturn.png` | sun, white hole, Saturn ring |
| `scene/ice_crystal.png`, `scene/glass_shard.png`, `scene/ember_petal.png`, `scene/shadow_blob.png`, `scene/clock_face.png`, `scene/flash_white.png` | billboards / rings of the other domains |
| `scene/glow_soft.png`, `scene/sun_corona.png`, `scene/white_hole_rays.png`, `scene/shockwave.png` | glow halos, sun corona, white-hole rays, expanding impact shockwave ring; also used by the sphere's glow shell |

## Impact frames

`textures/impact/<domain>/frame_01.png … frame_03.png` – referenced by name from the sequence files (`"texture": "frame_02"`).
Any number of frames can be added; just reference the new names. Hard frames are softened automatically when "reduced flashes" is on.

## Sounds

`sounds.json` defines these events; every entry currently points at a vanilla sound (`"type": "event"`).
To use your own audio put an OGG (mono, 44.1 kHz) under `sounds/<path>.ogg` and change the entry to `{"name": "skysdomains:<path>"}`.

| Event | Used for |
|---|---|
| `skysdomains:domain.activate` | activation confirmed (server side) |
| `skysdomains:domain.denied` | activation refused |
| `skysdomains:domain.impact_frame` | generic impact frame hit |
| `skysdomains:domain.clash` | domain clash |
| `skysdomains:collapse.planet_launch` | planet leaves the white hole |
| `skysdomains:collapse.planet_impact` | planet impact |
| `skysdomains:collapse.sun_impact` | final sun impact |
| `skysdomains:collapse.white_hole` | white hole forms |
| `skysdomains:glass_heaven.shatter` | projectile shatters on the Glass Heaven wall |

## Sequence files

`sequences/<domain>.json` – see [SEQUENCES.md](SEQUENCES.md).

## Post effects

`post_effect/<name>.json` + `shaders/post/<name>.fsh`: `invert`, `desaturate`, `chromatic`, `radial_blur`, `heat`. Referenced by the `post_shader` / `invert` actions.
